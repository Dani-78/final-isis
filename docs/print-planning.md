# Planificación del proyecto

## 1. Problema seleccionado

### Rediseño de la interfaz de consulta bibliotecaria

El problema seleccionado es la **organización poco clara de la interfaz de consulta bibliotecaria**, debido a que la distribución actual de las funcionalidades puede dificultar la navegación y el proceso de búsqueda de información.

La propuesta consiste en reorganizar las funcionalidades existentes y mejorar la interfaz para que los usuarios puedan identificar fácilmente las diferentes opciones de búsqueda, explorar recursos por categorías y acceder a los canales de ayuda de la biblioteca.

## 2. Objetivo del proyecto

Mejorar la experiencia de los usuarios al consultar los recursos disponibles en la biblioteca mediante el rediseño de la interfaz de consulta.

El proyecto busca:

* Simplificar el proceso de búsqueda.
* Organizar mejor las opciones disponibles.
* Facilitar la identificación de cada funcionalidad.
* Mejorar la presentación visual.
* Reducir los pasos necesarios para realizar una consulta.
* Hacer más accesibles las opciones de ayuda y contacto.

## 3. Alcance

El proyecto se concentrará en la interfaz de consulta bibliotecaria y en la forma en que los usuarios interactúan con las diferentes herramientas del sistema.

### Incluye

* Rediseño de la pantalla principal de consulta.
* Búsqueda general.
* Búsqueda temática.
* Organización de filtros y criterios de búsqueda.
* Presentación de resultados.
* Acceso a información de los recursos.
* Opciones de contacto y ayuda.
* Mejoras de navegación.
* Mejoras de diseño visual y experiencia de usuario.

### No incluye

* Modificación de las bases de datos internas de la biblioteca.
* Modificación de los procesos administrativos.
* Cambio de los sistemas internos utilizados por el personal.
* Reemplazo de las funcionalidades que actualmente ofrece el sistema.

## 4. Funcionalidades principales

### 4.1 Búsqueda general

La interfaz permitirá realizar búsquedas utilizando diferentes criterios:

* Palabra clave.
* Autor.
* Título.
* Tipo de material.
* Año de publicación.
* Idioma.
* Área temática.

La búsqueda contará con botones claramente identificados para:

* Buscar.
* Limpiar filtros.

### 4.2 Búsqueda temática

Se incorporará una sección específica para explorar los recursos según diferentes categorías.

Entre las categorías iniciales se encuentran:

* Arquitectura.
* Bases de datos.
* Redes.
* Programación.
* Sistemas operativos.
* Seguridad informática.
* Inteligencia artificial.
* Otros.

También se permitirá realizar búsquedas mediante palabras clave relacionadas con cada área.

### 4.3 Contacto y ayuda

Las opciones de asistencia estarán disponibles de manera visible desde la interfaz.

Se contemplan:

* Chat con un bibliotecario.
* Envío de mensajes.
* Solicitud de ayuda.
* Información de contacto.
* Horarios de atención.

## 6. Prioridades

### Prioridad alta

* Búsqueda general.
* Organización de los criterios de búsqueda.
* Visualización de resultados.
* Navegación principal.
* Diseño de la interfaz.

### Prioridad media

* Búsqueda temática.
* Filtros adicionales.
* Información detallada de los recursos.
* Opciones de ayuda.

### Prioridad baja

* Personalización visual.
* Funcionalidades adicionales.
* Mejoras que no sean necesarias para el funcionamiento principal.

## 7. Criterios de aceptación

La solución se considerará funcional cuando:

* El usuario pueda identificar fácilmente dónde realizar una búsqueda.
* Los criterios de búsqueda estén claramente organizados.
* Las diferentes modalidades de búsqueda sean fáciles de distinguir.
* Los resultados sean fáciles de interpretar.
* La navegación entre las secciones sea clara.
* Las opciones de ayuda y contacto sean fácilmente visibles.
* La interfaz conserve las funcionalidades principales del sistema original.
* Las pruebas realizadas no presenten errores críticos.
