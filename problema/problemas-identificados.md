# Problemas identificados

A partir de las observaciones realizadas, se identificaron los siguientes problemas:

## Problema 1. Organización poco clara de las funciones

Las diferentes herramientas de consulta se encuentran agrupadas en formularios y menús, lo que puede dificultar que el usuario identifique rápidamente qué función necesita utilizar.

## Problema 2. Dificultad para realizar una búsqueda

El usuario debe interactuar con diferentes campos y opciones para realizar una consulta, lo que puede hacer que el proceso resulte más complejo de lo necesario.

## Problema 3. Falta de diferenciación entre tipos de búsqueda

La búsqueda general y la búsqueda temática no están suficientemente diferenciadas, lo que puede dificultar que el usuario determine cuál opción se adapta mejor a la información que desea encontrar.

## Problema 4. Baja visibilidad de las opciones de ayuda

Las alternativas para contactar al personal de la biblioteca no tienen suficiente protagonismo dentro de la interfaz. Esto puede dificultar que un usuario encuentre ayuda cuando tiene problemas durante la consulta.

## Problema 5. Exceso de información presentada simultáneamente

La presencia de numerosos campos, opciones y elementos dentro de la misma interfaz puede generar una experiencia visual poco clara y dificultar la navegación.

## Problema 6. Interfaz poco intuitiva para usuarios nuevos

La distribución actual de los elementos puede hacer que una persona que utiliza el sistema por primera vez necesite explorar diferentes opciones antes de comprender cómo realizar una consulta.

## Problema 7. Apariencia visual desactualizada

La interfaz presenta características visuales que pueden percibirse como poco modernas frente a las expectativas actuales de los usuarios de plataformas digitales.
